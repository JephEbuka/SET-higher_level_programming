# JavaScript - Web Scraping

This project covers file operations, HTTP requests, APIs, JSON parsing, and web scraping using JavaScript and Node.js.

## Requirements

- Ubuntu 20.04 LTS
- Node.js 14.x
- Semistandard
- Request module
- All JavaScript files start with `#!/usr/bin/node`
- All JavaScript files are executable
- The use of `var` is not allowed

## Tasks

### 0-readme.js
Reads and prints the contents of a file using UTF-8 encoding.

### 1-writeme.js
Writes a string to a file using UTF-8 encoding.

### 2-statuscode.js
Sends a GET request and prints the HTTP response status code.

### 3-starwars_title.js
Uses the Star Wars API to print a movie title from its movie ID.

### 4-starwars_count.js
Prints the number of Star Wars movies containing Wedge Antilles.

### 5-request_store.js
Gets the contents of a webpage and saves the response body to a file.

### 6-completed_tasks.js
Computes the number of completed tasks for each user from an API.

### 100-starwars_characters.js
Prints all characters from a Star Wars movie using the Star Wars API.

### 101-starwars_characters.js
Prints all characters from a Star Wars movie in the same order as the characters list returned by the films API.
